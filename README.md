## Instalations
```
$ pkg update -y && pkg upgrade -y
$ apt update -y && apt upgrade -y
$ pkg install git
$ pkg install python -y
$ git clone https://github.com/Whomrx666/doxxerX.git
$ cd doxxerX
$ pip install -r requirements.txt
```
